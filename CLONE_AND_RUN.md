# 🚀 Quick Clone & Run Guide\n\n## Step 1: Clone the Repository\n\n```bash\ngit clone https://github.com/lukmanmir682-ship-it/affiliate-ticket-booking.git\ncd affiliate-ticket-booking\n```\n\n## Step 2: Install Dependencies\n\n```bash\nnpm install-all\n```\n\nOr if you're using yarn:\n\n```bash\nyarn install\n```\n\n## Step 3: Install Frontend Dependencies\n\n```bash\ncd frontend\nnpm install\n```\n\nSpecific packages needed:\n```bash\nnpm install react react-dom lucide-react socket.io-client tailwindcss postcss autoprefixer\n```\n\n## Step 4: Setup Environment Variables (Optional)\n\nCreate `.env` files if needed:\n\n**frontend/.env**\n```\nVITE_API_URL=http://localhost:5000\n```\n\n**backend/.env** (if running backend)\n```\nPORT=5000\nMONGODB_URI=mongodb://localhost:27017/affiliate-tickets\nJWT_SECRET=your_jwt_secret_key\nNODE_ENV=development\n```\n\n## Step 5: Start the Development Server\n\nFrom the `frontend` directory:\n\n```bash\nnpm run dev\n```\n\nOr from the root directory:\n\n```bash\ncd frontend && npm run dev\n```\n\n## Step 6: Open in Browser\n\n🎉 Visit: **http://localhost:3000**\n\n---\n\n## 🕐 What You'll See\n\n- **Multi-Timezone Clock** with real-time updates\n- **17+ Global Timezones** (UTC, EST, PST, IST, JST, and more)\n- **Interactive Selection** - Click timezone buttons to add/remove\n- **Modern Dark Theme** with gradient UI\n- **Fully Responsive** - Works on mobile, tablet, desktop\n\n---\n\n## 📋 System Requirements\n\n- **Node.js** v18 or higher\n- **npm** v9 or higher (or yarn)\n- **Modern browser** (Chrome, Firefox, Safari, Edge)\n\n## ✅ Verify Installation\n\nCheck Node.js version:\n```bash\nnode --version  # Should be v18+\nnpm --version   # Should be v9+\n```\n\n---\n\n## 🛠️ Troubleshooting\n\n### Port 3000 Already in Use?\n\n```bash\n# Find and kill process on port 3000\nlsof -ti:3000 | xargs kill -9\n\n# Or specify different port\nnpm run dev -- --port 3001\n```\n\n### Dependencies Not Installing?\n\n```bash\n# Clear npm cache\nnpm cache clean --force\n\n# Delete node_modules and reinstall\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### Tailwind CSS Not Loading?\n\n```bash\n# Rebuild Tailwind\nnpm install -D tailwindcss postcss autoprefixer\nnpx tailwindcss init -p\n```\n\n### TypeScript Errors?\n\n```bash\n# Install TypeScript\nnpm install -D typescript\n```\n\n---\n\n## 📁 Project Structure\n\n```\naffiliate-ticket-booking/\n├── frontend/ `frontend/src/components/MultiTimezoneClck.tsx`:\n\n```tsx\n// Change from blue to purple\nclassName=\"bg-gradient-to-br from-purple-900 via-purple-800 to-purple-900\"\nclassName=\"text-purple-400\"\n```\n\n### Add More Timezones\n\nIn `MultiTimezoneClck.tsx`, add to the `allTimezones` array:\n\n```tsx\nconst allTimezones: Timezone[] = [\n  // ... existing timezones\n  { name: 'BRT', offset: 'America/Sao_Paulo', city: 'São Paulo' },\n  { name: 'CAT', offset: 'Africa/Cairo', city: 'Cairo' },\n];\n```\n\n### Change Update Frequency\n\nIn the `useEffect` hook, adjust the interval:\n\n```tsx\nconst timer = setInterval(() => {\n  setCurrentTime(new Date().toLocaleTimeString());\n}, 500);  // Update every 500ms instead of 1000ms\n```\n\n---\n\n## 🚀 Deploy to Production\n\n### Option 1: Vercel (Recommended)\n\n```bash\n# Install Vercel CLI\nnpm i -g vercel\n\n# Deploy\nvercel\n```\n\n### Option 2: Netlify\n\n```bash\n# Build the frontend\ncd frontend\nnpm run build\n\n# Deploy the dist folder to Netlify\nnetlify deploy --prod --dir=dist\n```\n\n### Option 3: Docker\n\nCreate `Dockerfile` in frontend:\n\n```dockerfile\nFROM node:18-alpine\nWORKDIR /app\nCOPY package*.json ./\nRUN npm install\nCOPY . .\nRUN npm run build\nEXPOSE 3000\nCMD [\"npm\", \"run\", \"dev\"]\n```\n\nBuild and run:\n```bash\ndocker build -t affiliate-clock .\ndocker run -p 3000:3000 affiliate-clock\n```\n\n---\n\n## 📞 Support\n\n- **Repository**:
